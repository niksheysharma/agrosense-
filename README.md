# AgroSense 🌾

**Problem Statement:**
> "30-40% of crop yield is lost due to late-stage disease detection and blind fertilization. Existing tools are fragmented — farmers need a unified platform combining deep learning crop diagnosis with real-time IoT soil intelligence."

## 🚀 The Solution: A Unified Agricultural Intelligence Platform

AgroSense bridges the gap between disconnected farming tools by offering a seamless, single-platform experience that combines **Deep Learning for Crop Diagnosis** and **Real-Time IoT Soil Intelligence**. 

By bringing these two critical pillars of agriculture together, AgroSense eliminates blind fertilization and catches crop diseases in their earliest stages, aiming to recover the 30-40% of crop yield typically lost to these issues.

## ✨ Key Features

1. **Integrated Deep Learning & IoT Analysis**
   - Correlates image-based disease symptoms with real-time soil data (Nitrogen, Phosphorus, Potassium, Moisture, pH, Temp) to determine the exact root cause of plant distress.
   - For example: It identifies yellowing leaves and cross-references with low soil nitrogen levels to confirm a nutrient deficiency rather than relying solely on visual symptoms.

2. **Real-Time Soil Health Dashboard (IoT)**
   - Live monitoring of NPK values, pH levels, moisture, and temperature.
   - Prevents "blind fertilization" by delivering precise, targeted recommendations based on actual soil deficits.

3. **On-Device Plant Disease Detection (Deep Learning)**
   - Fast, offline-capable image scanning to detect early-stage diseases before they spread across the field.

4. **Inclusive, Localized Accessibility**
   - Multi-lingual support (English & Hindi built-in) ensuring accessibility for regional farmers.
   - Text-to-speech feature that reads out the diagnosis and action plan for farmers who prefer audio guidance.
   - "Offline-ready" architecture to accommodate remote farm locations with poor connectivity.

## 🛠 Tech Stack
- **Frontend Core:** HTML5, CSS3, Vanilla JavaScript.
- **Design System:** Custom CSS properties, modern glassmorphic and card-based UI, responsive mobile-first layout.
- **Simulated Backend/AI:** Simulated deep learning inference delays and IoT data correlation driven by a local JavaScript rules engine.

## 🏁 Getting Started
1. Clone or download the repository.
2. Open `index.html` in your modern web browser.
3. Use the **Language Toggle** in the top right to switch between English and Hindi.
4. Go to the **Scan** tab and click on the upload area to simulate diagnosing a leaf and viewing the correlated IoT soil root-cause analysis.
5. Go to the **Soil** tab to view the real-time environment metrics and precise fertilization recommendations.
